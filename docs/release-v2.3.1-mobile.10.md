# 澜音 · CeruMusic 手机版 v2.3.1-mobile.10

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.10

## 状态栏重做：透明沉浸式

之前几版一直在和「浅色背景 + 白色图标」较劲，这一版不再靠改底色兜底，而是把状态栏真正做成全面屏样式：

- 状态栏背景改为**全透明**，页面渐变直接延伸到屏幕顶部，不再是贴在上面的一条纯色
- 浅色主题使用深色图标，深色主题和播放页使用浅色图标，跟随页面实时切换
- 新增原生 `SystemBars` 插件，直接测量状态栏 / 系统导航栏的真实高度，刘海屏、挖孔屏、手势导航都不会再遮挡内容，也不会重复留白
- 启动、切页、切换主题、旋转屏幕、从后台回前台时都会重新同步
- 系统导航栏底色和图标明暗跟随主题，深色模式下不再露出一条浅色底

## UI：接入 Ionic Vue

- 应用外壳改用 Ionic 的 `ion-app`，底部导航换成 Ionicons 线性图标（选中态为实心图标）
- 颜色、字体、背景等设计变量接入 Ionic 主题体系，保留了原来的澜音平面风格，没有换成 Material 的厚重观感
- 发现页重做：品牌图标 + 大标题「发现音乐」、整块可点的搜索框、顶部渐变背景

## 修复

- 深色主题下标题和正文变成深色（Ionic 默认文本色覆盖了应用配色）
- 深色主题下发现页仍是浅色渐变、搜索框仍是白底
- 深色主题下底部导航栏仍是白色
- 播放页顶部/底部改用真实安全区变量，全面屏下不再被状态栏和手势条压住

## 继续包含

- 底部播放任务栏：实色贴底、顶部进度线、绿色圆形播放按钮
- 云歌词匹配：LrcLib + QQ 音乐，支持翻译与自动回退
- 底部 4 Tab、独立歌单页、歌单导入
- VPN/代理 fake-IP 下的插件链接导入
- 插件音质列表与「自动（最高）/超清母带」
- Android 前台媒体服务、歌词、收藏、播放历史
