# 澜音 · CeruMusic 手机版 v2.3.1-mobile.2

## 修复

- 修复开启 VPN / 代理时，插件链接被误判为「本机、回环或局域网地址」而无法导入的问题
  - 域名解析到 VPN fake-IP 网段（198.18.0.0/15、100.64.0.0/10、IPv6 ULA）时不再误拦
  - 直接填写私网 IP、localhost 等地址仍然会被拒绝
- 修复无法导入其他音乐平台歌单的问题
  - 「我的 → 歌单」新增「导入」入口
  - 支持插件声明的歌单导入器，可导入 QQ音乐、网易云音乐、酷狗、酷我、咪咕等平台歌单
  - 自动翻页、去重，并生成同名本地歌单
- 修复音质选项与插件能力不一致的问题
  - 默认改为「自动（最高）」，不再固定 128k
  - 音质列表从插件读取，支持标准、超高、无损、超高解析、高清臻音、全景环绕、全景增强、超清母带
  - 播放页与设置页统一显示中文音质标签，并支持手动切换
  - 当前音质不可用时自动回落到最接近的档位
