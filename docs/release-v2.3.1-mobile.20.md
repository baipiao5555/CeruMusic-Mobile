# 澜音 · CeruMusic 手机版 v2.3.1-mobile.20

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.20

这一版补两个基础体验：**歌曲可以加入歌单了**，以及 **Android 返回手势/返回键**。

## 歌曲更多操作

之前歌曲行只有收藏、下载和一个「加入播放队列」的加号，确实没有添加到歌单的入口。这一版把加号换成「更多」菜单：

- 添加到歌单：列出所有本地歌单，点一下即可加入；已经在歌单里会提示，不会重复添加
- 新建歌单并添加：在同一个弹层里输入名称，创建后直接把当前歌曲放进去
- 从当前歌单移除：在歌单详情里打开菜单才会出现
- 下一首播放
- 添加到播放队列
- 下载 / 查看是否已下载

菜单适配了安全区和底部导航，内容多时可以滚动。搜索、发现、收藏、历史、歌单详情等所有使用歌曲行的地方都有这个入口。

## Android 返回手势

之前没有监听系统返回，侧滑返回会直接退出或没有反应。现在：

- 有弹层（歌曲菜单、导入歌单、新建歌单、权限确认等）时，返回手势先关闭弹层
- 在设置、播放页、插件页、歌单详情等二级页面，返回上一页
- 在底部四个主页面（发现/搜索/歌单/我的）按返回才退出应用
- 从深链直接打开某个页面、没有历史记录时，返回到首页而不是卡住

## 验证

- 浏览器端到端：歌曲行出现「更多」按钮、原来的队列加号已移除；菜单包含下一首/队列/添加到歌单/下载；
  新建歌单并添加后本地歌单为 1 首；歌单详情里「从当前歌单移除」后变为 0 首并显示空状态；再次添加到已有歌单成功
- Vue Router 历史状态确认 `history.state.back` 正常写入，二级页面有可返回记录
- `vue-tsc` 类型检查、生产构建 0 报错，浏览器 console 无错误
- 返回手势依赖 Android 原生 `backButton` 事件，需要真机验证；代码路径为：关闭弹层 → 返回上一页 → 主页面退出
