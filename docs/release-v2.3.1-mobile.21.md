# 澜音 · CeruMusic 手机版 v2.3.1-mobile.21

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.21

这一版修复了重启后播放一直加载的问题，并补上左右滑动和一批设置项。

## 修复：关闭再打开后播放一直加载

原因：应用重启后播放器会从本地恢复队列和当前歌曲，但音频元素本身没有音源。此时点迷你播放器的播放按钮，代码只是在空的 `<audio>` 上调用 `play()`，某些 WebView 会一直挂起，界面就停在加载状态。

现在：

- 重启后点播放会走完整的 `startPlayback`：重新向插件解析当前歌曲，并从上次保存的位置继续
- 恢复时主动清掉旧音源、重置 loading/playing 状态
- 解析和起播增加了 25 秒超时兜底，超时会提示「加载超时，请重试或切换音源」，不会永久转圈
- 清空队列、移除当前歌曲时也改为真正移除 `src`，避免空元素被误判为已加载

## 左右滑动

- 播放页：左滑下一首，右滑上一首
- 主页面：在发现 / 搜索 / 歌单 / 我的之间左右滑动切换
- 两个手势都有独立开关，默认开启；弹层、输入框、横向滚动的音质/来源标签不会误触发
- 与 Android 系统边缘返回手势不冲突

## 设置项补齐

新增：

- **播放模式**：顺序播放 / 列表循环 / 单曲循环 / 随机播放，与播放页模式按钮同步
- **耳机拔出时暂停**：有线耳机或蓝牙音频断开时，原生媒体服务会收到系统广播并暂停
- **下载音质**：跟随播放音质，或单独指定标准 / 高品 / 无损 / 高清臻音等档位
- **同时下载数量**：1 / 2 / 3 个并发，原生下载线程池同步扩到 3
- **手势开关**：播放页滑动切歌、主页面滑动切换
