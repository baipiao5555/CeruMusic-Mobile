# 澜音 · CeruMusic 手机版 v2.3.1-mobile.23

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.23

这一版对照电脑端设置，补了手机端能直接复用的五项：主题色、歌词字号、播放倍速、下载文件名格式、歌单重命名。

## 对照电脑端补的设置

| 电脑端设置 | 手机端 | 说明 |
| --- | --- | --- |
| 应用主题色 | ✅ 新增 | 青绿 / 蓝 / 紫 / 橙，立即作用于按钮、标签、底栏指示器 |
| 歌词字号 | ✅ 新增 | 小 / 标准 / 大 / 特大，播放页歌词实时缩放 |
| 播放倍速 | ✅ 新增 | 0.75x / 1x / 1.25x / 1.5x / 2x，播放中切换立即生效 |
| 下载文件名格式 | ✅ 新增 | 支持 `%t` 歌名、`%s` 歌手、`%a` 专辑、`%u` 平台、`%q` 音质、`%d` 日期，带实时预览 |
| 播放列表管理 | ✅ 部分 | 歌单详情新增重命名；新建、删除、下载全部已有 |
| 音频均衡器 / 音效 / 音频输出 | ❌ | 手机端音频由 WebView `<audio>` 输出，没有可用的系统级均衡器管线 |
| 网络代理 | ❌ | 手机端跟随系统 VPN/代理即可；应用内代理还会与请求安全校验冲突 |
| 存储目录配置 | ❌ | Android 分区存储下不能任意指定目录 |
| 下载标签写入 / 歌词导出格式 | ❌ | 没有引入原生标签写入库，当前只保存音频文件 |
| 全局背景 / 窗口关闭行为 / 托盘 / 热键 / 悬浮球 | ❌ | 属于桌面窗口能力，手机端没有对应形态 |
| 播放时自动缓存 | ❌ | 当前是直接流式播放，缓存层需要单独设计 |

## 具体改动

- 设置页「外观」新增主题色选择，颜色通过 CSS 变量即时生效
- 设置页「播放」新增播放速度、歌词字号；播放页歌词字号用 `--lyric-scale` 实时缩放
- 设置页「下载」新增文件名格式输入框、占位符说明和示例预览
- 下载时按模板生成文件名，非法字符仍会过滤，扩展名继续按 URL/音质推断
- 歌单详情右上角新增编辑按钮，可以重命名歌单

## 验证

- `vue-tsc` 类型检查、生产构建 0 报错
- 浏览器端到端：主题色切换后 `--brand` 变为对应值；播放速度 1.5x 和歌词字号「特大」正确持久化；
  文件名模板 `%a - %t` 预览为「十一月的萧邦 - 夜曲.mp3」；格式化函数输出「示例音源_周杰伦_晴天」；
  歌单重命名后本地数据从「旧名字」变为「新名字」
- Android 原生工程未改动，沿用 .22 的媒体服务与歌词共享实现
