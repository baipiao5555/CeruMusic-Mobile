# 澜音 · CeruMusic 手机版 v2.3.1-mobile.24

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.24

这一版补齐播放页本身的设置：不用再退回设置页找选项。

## 播放页设置面板

播放页右上角新增齿轮按钮，打开后可以直接调整：

- **播放速度**：0.75x / 1x / 1.25x / 1.5x / 2x，播放中切换立即生效，保持音调
- **歌词字号**：小 / 标准 / 大 / 特大，歌词实时缩放
- **歌词偏移**：-0.5s / -0.2s / 0s / +0.2s / +0.5s；正值表示歌词延后显示，点击歌词跳转时也会按偏移量校正
- **显示翻译**：关闭后隐藏歌词下方的翻译行
- **定时停止**：关闭 / 15 分钟 / 30 分钟 / 60 分钟 / 播完当前歌，面板内实时显示剩余时间
- **下载当前歌曲**：直接加入下载队列

这些选项和设置页共用同一份本地配置：在播放页改了播放速度或歌词字号，设置页里也会同步显示。

## 验证

- 浏览器端到端：播放页设置面板包含全部六项；歌词翻译行从 1 条变为 0 条；设置 15 分钟定时后 `sleepEndAt` 正确写入；切换「播完当前歌」后 `sleepAtTrackEnd=true`；点击「下载当前歌曲」后下载任务完成
