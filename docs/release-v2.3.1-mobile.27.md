# 澜音 · CeruMusic 手机版 v2.3.1-mobile.27

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.27

这一版集中修补播放状态的几个边界问题。

## 播放 / 暂停

- 歌曲地址还在解析时暂停，再点播放会重新开始当前选中的歌，不会恢复上一首
- 切歌加载中暂停，进度条不再显示上一首的时间
- 缓冲时按暂停后可以正常继续，不再卡在加载状态
- 加载失败或超时会停掉上一首音频并清理旧音源，不再出现「界面已停止但声音还在响」

## 队列

- 加载中清空播放队列，或删除正在加载的最后一首歌，地址返回后不会再自动播放
- 恢复上次队列时校验索引，避免记住的索引越界导致无法播放

## 音质与进度

- 暂停状态下切换音质，继续播放时会按新音质重新加载，而不是继续播旧音质
- 播放中每 5 秒以及暂停时保存播放位置，重新打开 App 恢复到更接近上次停止的位置

## 验证

- 浏览器端到端：A 歌曲播放中切到 B，B 加载中点暂停，等待地址返回后确认不播放；再点播放从 B 开始而不是恢复 A
- 加载中清空队列，2.2 秒后地址返回仍保持停止
- 暂停时从 128k 切到 flac，恢复播放触发第二次解析并请求 flac 音质
- 播放 6 秒后刷新页面，恢复位置为约 5.5 秒
- 解析失败后点播放不会恢复上一首；普通暂停/恢复位置正常
- `vue-tsc` 类型检查、生产构建 0 报错
