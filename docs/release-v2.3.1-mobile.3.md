# 澜音 · CeruMusic 手机版 v2.3.1-mobile.3

## 本次优化

- 底部导航新增独立「歌单」Tab
  - 从任意页面一键进入歌单，不再需要「我的 → 歌单」
  - 歌单页集中展示全部歌单、歌曲总数、导入/新建入口
  - 打开本地歌单详情时，底部「歌单」保持高亮
- 「我的」页右上角 `+` 改为「添加歌单」快捷操作
  - 可选择「新建歌单」或「导入歌单」
  - 原 `+` 会跳到音源插件页，容易误解
- 保留原有视觉风格和「我的」页的歌单分区，作为第二个入口

## 仍然包含

- 插件链接在 VPN/代理 fake-IP 环境下的导入修复
- 通过插件导入 QQ音乐、网易云音乐、酷狗、酷我、咪咕等平台歌单
- 插件驱动的音质列表与「自动（最高）」，支持超清母带等标签
- Android 前台媒体服务、歌词、收藏、播放历史
