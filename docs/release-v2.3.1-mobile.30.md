# 澜音 · CeruMusic 手机版 v2.3.1-mobile.30

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.30

这一版重做了歌单详情页，并加入批量选择。

## 歌单详情页

- 顶部改为「返回 + 歌单标题 + 重命名/删除」的居中导航栏
- 歌单封面卡片使用封面图做虚化背景，封面加大，标题和歌曲数层级更清晰
- 播放全部、下载、选择三个操作统一放在封面下方，窄屏自动换行
- 歌曲列表增加「歌曲 / 数量 / 批量选择」标题行

## 批量选择

- 点击「批量选择」或封面下方的「选择」进入选择模式
- 每首歌前显示圆形勾选框，点击整行即可选中/取消
- 支持「全选 / 取消全选」
- 底部浮动操作栏：已选数量、下载选中、加入播放队列、移出歌单
- 移出歌单前会二次确认；操作完成后自动退出选择模式
- 选择模式下隐藏单曲的收藏/下载/更多按钮，避免误触

## 验证

- 浏览器端到端：6 首歌单进入选择模式后出现 6 个勾选框；选中 2 首显示 2；全选显示 6
- 批量加入队列后播放队列为 6 首；批量移出 1 首后歌单剩 5 首
- 390px 手机宽度下封面、按钮、列表和底部操作栏无溢出
- `vue-tsc` 类型检查、生产构建通过
