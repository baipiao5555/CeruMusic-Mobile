# 澜音 · CeruMusic 手机版 v2.3.1-mobile.40

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.3.1-mobile.40

这一版做了界面优化：播放器改成悬浮小卡片，歌单选择入口收成一个文字按钮。

## 播放器

- 迷你播放器不再通栏贴底，改成和底部导航同宽的悬浮圆角卡片
- 卡片顶部保留细进度线，封面、歌名和歌手整体缩小，减少对页面内容的遮挡
- 播放键改成浅绿色圆形按钮，和底部导航的选中态一致
- 卡片与底部导航保持 14px 左右边距，页面底部预留对应滚动空间

## 歌单选择

- 去掉歌单头部重复的「选择 / 批量选择」入口，只在「歌曲 N」右侧保留一个纯文字「选择」
- 没进入选择模式时不显示任何勾选圈；进入后每首歌左侧才出现圆形选择框
- 选择模式下顶部改为「全选 / 取消全选」，底部操作条提供取消、已选数量、下载、队列、移出
- 歌曲行去掉专辑后缀，避免歌手名被来源/音质标签挤成省略号

## 验证

- `vue-tsc` 类型检查、生产构建通过
- 浏览器 390 × 844 视口逐页截图检查：发现、歌单、我的、搜索，以及歌单选择模式
- 播放器与底部导航、选择操作条不重叠，页面底部滚动空间正常
- Android 原生工程编译通过，APK 使用与原版相同的签名
- 当前环境没有连接 Android 设备，真机上的状态栏、手势和安装覆盖未做验证
