# 澜音 · CeruMusic 手机版 v2.3.1-mobile.5

## 新增：云歌词匹配

参考 [tomakino/LyricProvider](https://github.com/tomakino/LyricProvider) 的云歌词提供器思路，接入两个公开歌词源：

- **LrcLib**：按曲名 + 歌手搜索同步歌词
- **QQ音乐**：搜索歌曲并读取公开歌词接口，支持翻译

行为：

- 插件提供的歌词为空时，自动匹配云歌词
- 播放页显示「歌词来源：LrcLib / QQ音乐」
- 没有歌词时提供「在线匹配歌词」按钮，可手动重试
- 设置 → 播放 → 「自动匹配云歌词」可关闭
- 会按曲名、歌手、专辑、时长和是否有翻译综合评分，避免匹配到错误歌曲
- 中文歌曲优先 QQ音乐，英文歌曲优先 LrcLib；某个源失败会自动回退另一个

## 修复

- 歌单导入支持直接粘贴平台分享文案：会自动提取其中的链接或歌单 ID，不再把整段文案当成 URL 导致导入失败
- 导入弹窗输入框下方补充了对应提示

## 仍然包含

- Android 状态栏颜色/图标跟随主题（浅色、深色、播放页）
- 底部 4 Tab：发现 / 搜索 / 歌单 / 我的
- 独立歌单页、歌单导入、新建/导入快捷操作
- VPN/代理 fake-IP 环境下的插件链接导入
- 插件音质列表与「自动（最高）/超清母带」
- Android 前台媒体服务

## 隐私与安全

- 云歌词请求只发送曲名、歌手、专辑和时长到 LrcLib / QQ音乐
- 可在设置中关闭自动匹配
- 网络请求仍走应用的公网 HTTP(S) 校验，拒绝 localhost、回环、私有与保留地址
