# 澜音 · CeruMusic 手机版 v2.4.0（正式版）

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.4.0

这是手机版的第一个正式版本，汇总了最近几轮的界面、歌词共享、日志和动画改进。

## 逐字歌词动画

- 播放页当前歌词改成逐字变色：唱到的字变成品牌绿色，未唱到的字保持白色
- 颜色按当前行时间轴推进，带轻微过渡，长句不会一次全部变色
- 行结束时间缺失或异常拉长时，动画会自动收敛到合理时长

## 歌词共享

- 修复 JS 浮点位置被原生 `getLong` 静默读成 0 的问题，共享进度不再反复回到开头
- 播放中收到略旧的进度会向前对齐，不再把歌词位置写回更早的值
- 拖动进度条走独立 seek 通道，仍然可以正常回退
- 插件只提供逐字时间时，用逐字内容拼出整行，避免只共享前几行

## 界面与动画

- 返回时页面从左侧滑入，前进时从右侧滑入；进入用弹性缓动，退出更快，减少等待感
- 系统开启「减少动画」时退化为纯淡入淡出
- 迷你播放器保留悬浮卡片样式，包含上一首 / 播放暂停 / 下一首
- 歌单选择只保留一个纯文字入口，歌曲行的歌手名可以完整显示

## 运行日志

- 「我的 → 设置 → 音源与数据」新增两个开关：
  - **运行日志**：总开关，关闭后不再记录
  - **详细日志**：额外记录 `console.log / info / debug`，排查问题时开启
- 「我的 → 运行日志」可查看 JS 日志和原生歌词/播放日志，复制和导出时会一起附带
- 不再单独发布 debug APK，一个安装包即可完成排查

## 验证

- `vue-tsc` 类型检查、生产构建通过
- Android Java 编译通过，APK 使用与原版相同的签名
- 浏览器验证：逐字歌词变色、日志开关、前进/返回过渡动画均正常
- 当前环境没有连接小米 13 真机，状态栏歌词与安装覆盖需要在真机上确认
