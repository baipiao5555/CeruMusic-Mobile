# 澜音 · CeruMusic 手机版 v2.4.6

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.4.6

这一版重做搜索页：不用按回车、也不用打全名，打一个字就出相关歌名。

## 边打边搜

- 输入停止 260ms 后自动搜索，不再需要按回车或点「搜索」
- 中文输入法组词期间不触发搜索，拼音打到一半不会被当成关键词
- 连续快速输入时按请求序号丢弃过期响应，旧结果不会盖住最新结果
- 搜索过程中保留上一批结果，标题旁显示「搜索中…」，页面不再整块空白

## 联想与历史

- 输入一个字就在搜索框下方弹出歌名 + 歌手，点一下直接搜；音源给出结果后自动收起
- 联想词来自收藏、本地歌单，以及搜过 / 在榜单和歌单里见过的歌，不依赖网络
- 「最近搜索」持久保存，只记真正搜出结果的词，不会塞进「晴」「晴天」这类半成品，支持一键清空

## 结果质量

- 结果按相关度重排：歌名全等 > 歌名前缀 > 歌名包含 > 歌手 / 专辑包含
- 歌名和歌手里命中的片段高亮显示
- 搜索结果显示条目数，并保留「播放全部」

## 搜不到时的兜底

- 「歌名 歌手」这种写法如果音源不认，会自动只用歌名重搜一次，并在结果上方注明「已按…搜索」
- 超长关键词再退一步用前半段重试
- 音源完全没结果时，从本地索引（收藏、歌单、搜过的歌）里找出匹配项，标为「本地歌曲」

## 其他

- 榜单 / 歌单加载时把歌曲送进本地索引，搜索联想更早就能用
- 歌曲行组件新增可选高亮参数，歌单、我的、播放页渲染与之前一致
- 修复从插件跳转到搜索页时带 `?q=` 不会换词重新搜索的问题

## 验证

- `vue-tsc` 类型检查、生产构建通过
- 模拟运行（Playwright，两个假音源：模糊匹配 / 只认全名）16 项全部通过：单字出结果、联想点击、历史记录、缩词兜底、本地兜底、快速连续输入、无控制台报错
- 歌单详情与我的页面歌曲行无多余高亮，渲染正常
- 当前环境没有连接真机
