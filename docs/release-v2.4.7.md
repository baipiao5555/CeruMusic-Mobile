# 澜音 · CeruMusic 手机版 v2.4.7

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.4.7

这一版取消「边打边搜」，并给音源插件加上真正的自动更新。

## 搜索：输入时不再自动联网

- 打字只更新本地联想，不再每次输入都向音源发一次请求
- 只有这三种情况才真正搜索：按回车、点「搜索」按钮、点联想项或历史词
- 联想面板第一行固定是「搜索「xxx」」，点它就搜当前输入
- 联想内容全部本地生成：收藏、本地歌单、之前搜到过的歌
- 搜索历史仍然只记真正提交并搜出结果的词

其余搜索改进保留：结果按相关度排序（歌名全等 > 前缀 > 包含 > 歌手/专辑）、命中片段高亮、「歌名 歌手」搜不到时自动缩词重试、音源零结果时退回本地歌曲。

## 音源插件自动更新

- 应用启动后静默检查所有「从链接安装」的插件，有新版本自动替换，并弹出「已更新到 vX」
- 6 小时内只检查一次，不重复走网络；单个插件失败不影响其它插件，也不阻塞启动
- 设置 → 关于澜音 → 「插件自动更新」可以整体关闭（默认开启）
- 插件页新增「检查全部更新」，可立即检查，结果会列出「旧版本 → 新版本」
- 从文件安装的插件没有更新地址，不会自动更新，需要重新从链接安装一次

## 其他

- 更新后的插件保留原来的启用状态与更新地址，播放器会自动使用新版本
- 插件页帮助文案补充了自动更新的规则

## 验证

- `vue-tsc` 类型检查、生产构建通过
- 搜索模拟（Playwright + 假音源）15 项全部通过：输入一个字不产生任何请求、回车/按钮/联想才发请求、历史只记提交过的词、缩词兜底、本地兜底、高亮、快速输入只留最后一次结果
- 插件更新模拟 7 项全部通过：链接安装记录地址、手动检查发现并替换新版本、6 小时节流、启动自动更新到 3.0.0、关闭开关后不再更新
- 当前环境没有连接真机
