# 澜音 · CeruMusic 手机版 v2.5.0

基于 [timeshiftsauce/CeruMusic](https://github.com/timeshiftsauce/CeruMusic) v2.3.1 移植的 Android 应用。

- GitHub 仓库：https://github.com/baipiao5555/CeruMusic-Mobile
- Release 下载：https://github.com/baipiao5555/CeruMusic-Mobile/releases/tag/v2.5.0

这一版是**全站界面重制**：从配色、字体、组件到每一个页面都按「青瓷 · 釉光」重新画过，功能一个没少。

## 设计方向

界面语言取自项目名里的「青瓷」：梅子青做主色、瓷白做底、宋体做标题，配冰裂纹、釉光光斑、封面取色和一体化底部浮岛四个签名元素。硬编码的 80 行 hex 与 87 行 rgba 全部收进一套设计令牌（颜色 / 圆角 / 阴影 / 动效 / 字号），暗色主题同步重做。

## 各页变化

- **外壳**：底部改为玻璃浮岛——迷你播放器 + 四个 tab 合成一张卡；播放页自动隐藏
- **发现**：继续播放 hero 卡（封面底 + 进度 + 播放圆钮）、音源 chips、3:4 大序号榜单卡、推荐歌单加分类切换、最近播放
- **搜索**：真输入框 + 搜索历史 chips + 热词；结果页补齐「无插件 / 出错 / 零结果」三态，本地结果单独分组
- **歌单**：三列封面网格 + 排序 chips（最近更新 / 名称 / 曲数 / 云端）+ 虚线新建卡
- **我的**：资料卡三统计 + 本机占用进度 + 四个快捷入口 + 歌曲 / 专辑 / 歌手 / 文件夹四段
- **歌单详情**：封面出血到屏幕顶部 + 流内操作条（播放全部 / 随机 / 多选）
- **播放页**：暗釉沉浸，封面带釉光、68px 白圆主控、五项次级操作，底部两行歌词预览即上滑把手
- **歌词页**：封面模糊底、逐字卡拉 OK、行尾翻译，偏移与字号在顶栏直接可调
- **队列**：上方压暗正在播放条 + 下方 74vh 面板，三档筛选，行内可删
- **设置**：22 项设置分 7 组，新增设置项搜索；选择器与跳转的箭头语义分开
- **插件 / 云端 / 下载 / 日志 / 更新**：全部重画，日志支持 5 级筛选单行排开，更新页大号显示已安装版本

## 顺手修掉的旧问题

- 播放页「收起」原本是把返回箭头转 90°，现在是真的向下箭头，也支持下滑收起
- 8 处 `window.confirm` 换成统一样式的底部弹层
- 空态、错误态、加载态彻底分开（以前「没搜到」会显示成红色错误）
- 搜索结果里的高亮不再是浏览器默认的黄底
- 队列与设置弹层在暗色播放页里曾经白字白底，已修
- 大量 32px 的图标按钮、11.5px 以下的小字统一到可点 44px / 字号 11px 下限

## 功能保全

设置 22 项、播放页 22 项操作、插件安装 / 权限 / 配置 / 更新分支、云端歌单导入、下载队列、日志导出、歌词偏移与共享，全部保留；视图代码量整体上涨（Player 1289 行、Settings 1129 行、Plugins 927 行），没有删功能。
