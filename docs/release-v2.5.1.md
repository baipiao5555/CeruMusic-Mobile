# Ceru Music Mobile v2.5.1

一次以真机反馈为起点的修复版本。界面语言不变，修的是"在手机上真的用起来别扭"的地方。

## 这一版修了什么

### 1. 设置页的选择器不再"文字压在一起"

真机上点「默认音质」「下载音质」这类设置行时，行内的文字会突然和标题重叠，还会弹出一张铺满屏幕的安卓原生单选列表 —— 和整体界面完全不是一套东西。

原因是这些行用了一个透明铺满整行的原生 `<select>`，在桌面浏览器里点一下就失焦、看不出问题；真机上它拿到焦点后不释放，原生控件就显形了。

现在换成了应用自己的底部弹层（`OptionSheet`）：衬线标题、一行说明、每个档位名称 + 补充说明、右侧圆点选中，选中项用主色打勾。「歌词偏移」这种数值型选项用 chip 网格，一眼能扫完 -1.0s 到 +1.0s。

### 2. 播放页按屏幕高度自适应

在 1380×3036 这类长屏上，封面和进度条之间会出现一大片空白，进度条、控制区被推到下半屏，底部歌词又贴着屏幕边缘。

现在把封面 / 信息 / 进度 / 控制 / 次级操作包进一个整体居中的容器，间距改用 `clamp(vh)`，封面尺寸为 `min(320px, 78vw, 34vh)`：

- 375×667 的小屏不溢出、不做无效压缩；
- 390×844 常见尺寸比例正常；
- 460×1012 / 1380×3036 长屏不再出现空洞，歌词预览也有了下边距。

### 3. 页面内弹层被底部 TabBar 盖住（点不到）

歌单的「新建」「导入」等弹层原本渲染在页面容器里，而页面容器带着 `isolation: isolate`，把弹层困在了一个比底部浮岛更低的层叠上下文里 —— 视觉上弹层"缺一角"，点「创建」实际点到了 TabBar。

去掉这层隔离后，弹层正确盖住底部浮岛，菜单按钮也能正常点。

### 4. 其它细节

- 日志页的级别筛选（ALL / DEBUG / INFO / WARN / ERROR）在 320 / 360 宽的机型上不再横向溢出，五个 chip 等宽排开。
- 开关、纯文字按钮、"更多/全部"入口扩大了可点范围，不再需要精确点在小字上。
- 插件页「获取」按钮加高；资料库「＋ 新建」加高到 34px；播放页歌词预览与屏幕底边留出 18px。
- 播放页正在播放眉标 10px，暗色下的小号英文标签整体提亮一档。

## 新增：统一的二次确认

原来删除歌单、清空日志、退出登录、恢复默认设置、卸载插件、删除下载等 12 处用的是浏览器 `window.confirm` —— 真机上是一张灰扑扑的系统弹窗，和界面语言完全脱节。

现在统一为底部弹层：衬线标题 + 一句后果说明 + 「取消 / 确认」，危险操作用实色朱砂按钮，并说明"歌曲仍保留在资料库与本地文件里"这类上下文，避免误删焦虑。
