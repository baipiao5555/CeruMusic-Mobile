# Ceru Music v2.5.2

这一版是「看得见的空白」修复版：没有新增页面，全部围绕真机上暴露的三处问题。

## 封面不再是一块灰

- App 的默认封面原来只是一张灰白渐变占位图，任何没有封面的歌单、榜单、歌曲都会显示成一块空白。
  现在重绘成青瓷纹样：斜向青瓷渐变 + 釉光光斑 + 冰裂纹 + 中心音符，和界面语言一致。
- 同时去掉了 13 处 `<img loading="lazy">`。真机上这些图在滚动容器里不会触发加载，
  于是封面一直是空的 —— 现在进页面就加载，滚动时不会再出现灰色方块。

## 榜单卡上的白字看得清了

- 榜单卡顶部加了一层很淡的压暗遮罩，序号加大投影；
  白色数字压在浅色封面上也不会糊。

## 歌单页不再重复列出同一批歌单

- 原来「我的歌单」和「收藏的歌单」会把同一批云端歌单列两遍。
  现在合成一行「云端歌单 · N 张已同步到云端 · 与电脑版共用」，点进去就是云端页。
- 功能没有减少：新建、导入、删除、排序、云端筛选、进入详情都还在原位。

## 验证

- `npx vue-tsc --noEmit` 无报错，`npx vite build` 通过。
- 自动化巡检：场景 23 项、交互 21 项全部通过；截图复核 01/02/03/04/07 五屏无回归。
- 安装信息：`versionCode 24012`，`versionName 2.5.2`，与 2.5.x 系列同一签名，可直接覆盖升级。
