# CeruMusic 2.5.3

这一版只修显示，不动功能。

## 播放页：不再「摊开」

上一版把剩余高度平分给了「封面之上」和「歌词之下」，长屏手机（如 412×906、412×1080）上表现为两块大空洞：歌手名到底进度条之间空 120px，五项次级操作到歌词之间又空 100px。

- 封面、标题、进度、控制、次级操作改为**顶部锚定**，彼此间距固定 18–22px，不再随屏幕高度拉开。
- 剩余高度只留在歌词上方，歌词与底部对齐。
- 封面尺寸改为按屏幕高度计算 `min(340px, 80vw, 33vh - 6px)`：长屏更大，小屏（360×640）也不会溢出。

## 播放页：标题不再压进状态栏

`.p-top` 用 `padding` 简写把 `safe-t` 的 `padding-top` 覆盖成了 0，即使系统状态栏高度已知也用不上——真机上「正在播放 / 音源」和左右两个按钮会躲进状态栏里。

- `.p-top` 直接吃 `--safe-top`，模板里多余的 `safe-t` 一并删掉（播放页与全屏歌词页）。
- 原生侧 `applySystemInsets()` 在首帧量到 0 时不再把 0 写进 `--safe-top`，改为 0/240/600/1200/2400ms 多次重测，量到正值才覆盖。
- Android 上在拿到真实 insets 之前用 26px 兜底（`html.native-android:not(.insets-ready)`），避免旧机型首屏标题贴边。

## 其它

- 播放队列弹层底部留出系统手势条高度，最后一行不再被手势条压住。
- 自动化巡检里「更新页显示已安装版本」的断言改为不绑定具体版本号。

## 验证

- 四档屏幕注入真实状态栏高度后逐段测量：360×640 / 390×844 / 412×906 / 412×1080，均无溢出，内部间距一致。
- 23 项场景巡检 23/23 通过；`vue-tsc --noEmit` 与 `vite build` 均无错误。
- 打包后反查 APK 内 `Player-*.css`，确认 `.p-top{padding:calc(var(--safe-top) + 8px) ...}` 与 `.p-core{margin:0}` 已生效。
