# 澜音 v2.5.4

这一版只做打磨，不加新功能：把两处被反复提到的体验问题从根上改掉，顺手修掉一个会让人误会的播放按钮。

## 播放页的歌词预览

之前那两行歌词是「贴着屏幕底、跟着页面高度被推开」的——只要歌词稍微长一点，就会挤到最下面甚至被裁掉。现在改成一块固定高度的歌词窗：

- 当前句最多两行，长句自动换行并保留省略，不会再撑开页面；
- 下一句只占一行，超长省略，视觉上始终是「已唱 / 正在唱 / 下一句」的层次；
- 整块跟着封面、标题、进度条、控制区一起居中排布，不再在中间留下空洞；
- 小屏（≤700px 高，如 360×640）单独收紧间距与封面尺寸，整页不再溢出。

## 全屏歌词

- 列表改成真正的滚动容器：上留白让当前句落在屏幕上三分之一，下留白让最后一句也能滚到中间；
- 当前句 21px 衬线 + 左侧青条，已唱句更暗、未唱句更淡，长歌词滚起来不会顶到顶部；
- 滚动只作用于歌词容器本身（之前会连带整页跳动）。

## 返回首页不再重新加载

四个主页面（发现 / 搜索 / 歌单 / 我的）现在常驻内存：

- 切走再回来，不会再闪骨架屏、不会重新请求榜单与歌单；
- 滚动位置原样保留（keep-alive 会把页面移出文档导致 scrollTop 归零，回到页面时会补回去）；
- 手动下拉刷新 / 「重新加载」按钮仍然可用。

## 播放按钮的加载态

加载时原来显示三个点，和「更多」菜单长得一样。现在改为旋环，一眼能看出是在载入。

## 其它

- 日志、下载、更新等页面的版本号显示同步到 2.5.4；
