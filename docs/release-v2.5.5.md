# 澜音 v2.5.5

上一版把歌词挪到了页面底部，方向错了——歌词本来就该紧跟在歌名与歌手下面。这一版把它放回去，并把位置关系理顺。

## 播放页

从上到下现在是：封面 → 歌名 → 歌手 → **歌词（当前句 + 下一句）** → 进度条 → 控制区 → 五项操作。

- 歌词窗固定高度：当前句最多两行（长句换行、超出省略），下一句单行省略，任何长度的歌词都不会把页面撑开；
- 歌词与歌名之间 10–20px、与进度条之间 10–18px，形成「标题 / 副标题 / 歌词 / 操作」四段层次；
- 点歌词任意位置仍然进入全屏歌词；
- 矮屏（≤700px，如 360×640）单独收紧间距与封面尺寸，整页不溢出。

## 全屏歌词

- 上留白让当前句落在屏幕上三分之一，长歌词可以顺着往下滚；
- 滚动只作用于歌词容器，不再带动整页跳动。

## 其它（延续 v2.5.4）

- 四个主页面常驻内存，返回首页不再重新加载、滚动位置保留；
- 播放按钮加载态由三个点改成旋环。
