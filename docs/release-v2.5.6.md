# 澜音 v2.5.6

播放页底部的空白收掉了，整页的疏密重新排过。

## 播放页

- 封面由 33vh 放大到 37vh（412×907 上是 330px），把竖屏长出来的高度用掉，不再堆在底部；
- 四段间距重新标定：歌名区 2.4vh、歌词 2.2vh、进度条 2.2vh、控制区 2.8vh、五项操作 2.8vh，随屏高平滑缩放；
- 底部现在只剩那五个操作（喜欢 / 歌词 / 队列 / 定时 / 下载），下面就是安全区。播放页本来就故意不显示迷你播放器和底部导航——你已经在播放页里了，再挂一个迷你条没有意义；
- 矮屏（≤700px）依然单独收紧，360×640 实测底部 616 < 640，不溢出。

## 其它

- 四个主页面常驻内存、返回不重载；播放按钮加载态是旋环。
