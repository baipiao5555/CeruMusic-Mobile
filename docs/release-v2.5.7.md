# 澜音 v2.5.7

「播放设置」里的下载按钮被屏幕底边切掉半个——是 bug，已修。

## 原因

播放设置弹层原来整块 `overflow-y: auto`，高度上限 92vh。设置项加起来超过这个高度时，底部那颗「下载当前歌曲」就落到了可视区之外，只能靠滚动才能看到，截图里就是被切掉半截的样子。而且它贴着屏幕底边，没有给系统手势条留位置。

## 现在

弹层改成三段式：

- 顶部：抓手 + 标题「播放设置」+ 音源信息，固定不动；
- 中间：播放速度 / 歌词字号 / 歌词偏移 / 显示翻译 / 定时停止，独立滚动；
- 底部：下载按钮常驻，带一条分隔线和 `安全区 + 16px` 的下边距，任何屏高都不会被切。

实测：412×907 弹层 247–907，按钮 829–873，距屏底 34px；360×640 时中间区可滚动（415px 视口），按钮底 624 < 640，完整可见。

## 其它

- 播放页竖向节奏、歌词位置沿用 v2.5.6；
- 四个主页面常驻内存、返回不重载。
