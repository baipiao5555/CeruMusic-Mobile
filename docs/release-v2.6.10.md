# 澜音 v2.6.10

## 导入歌单没有歌词 / 不上岛

歌词共享本身不看歌单来源，它只看「这首歌有没有拿到带时间轴的歌词」。
导入歌单里的曲目，`ref` 可能是从云端记录重建出来的（只有 id 和音源），
插件拿不到内部的额外字段时就返回空歌词，于是岛和锁屏自然没有内容。

这一版补了三层兜底：

1. **插件取词为空或报错时，用「歌名 + 歌手」在同一个音源里再搜一次**，
   用搜索结果里完整的 `ref` 重取歌词；只认歌名一致的候选，不会贴错歌词。
2. **云端歌词允许按歌名匹配**：导入数据里歌手常写成「未知歌手 / 群星 / Unknown」，
   以前会因为歌手对不上被判负，现在只按歌名算分。
3. **日志里加了 LYRIC 诊断行**：清楚写着是「插件没给歌词」「插件取词失败」，
   还是「云端也没找到」，并带上音源与 ref id。

## 自查方法

播放一首那种歌单里的歌 → 设置 → 日志，找 `LYRIC` 开头的行：

- `source=plugin(按歌名重搜)`：兜底成功，岛上有歌词了。
- `插件没给歌词，改试云端歌词` 后面跟着 `歌词已加载`：云端兜底成功。
- `这句也没找到同步歌词`：这个音源与云端都没有这首歌的同步歌词，只能换音源。

## 其它导入方式

- 插件导入（浏览页里的歌单链接导入）：`ref` 是插件原生返回的，一直没问题。
- 桌面端/云端导入：`ref` 是重建的，就是这次修的场景。
- 各平台（酷狗 / QQ / 网易云 / 汽水）机制相同，出问题的条件也一样，所以修复对所有平台生效。
