# 澜音 v2.6.13

## 上一版为什么没用

2.6.12 的「岛歌词兼容」只是把歌词写进了媒体标题。小米超级岛读的不是媒体标题，
所以开关打开后岛上依旧空着——这条路本身不成立，我换掉了。

## 这一版换成真正的两条通道

1. **系统实时更新（Android 16 起，无需任何权限）**
   歌词被单独发成一张常驻通知：`setShortCriticalText(当前歌词行)` + 进度条 +
   `CATEGORY_STATUS`。Android 16 及以上的系统会把这类通知提升成岛卡片，
   岛上的主文案就是这句歌词。HyperOS 3 上这条路径不需要白名单。

2. **HyperOS 焦点通知（有白名单时优先）**
   同一张卡片再挂 `mFocusNotification` + `miui.focus.param`（param_v2：大岛左侧
   封面/前半句、右侧后半句，小岛进度环）+ `miui.focus.pics` 封面。
   识别到小米系机型才附带，没有白名单时系统会忽略这段，不会多出第二张卡。

媒体卡片保持原样（歌名、封面、上一首/播放/下一首），歌词走独立的
「岛歌词」通道，两者互不覆盖。

## 怎么试

设置 → 播放 → 打开「岛歌词兼容」→ 播一首**有歌词**的歌。

- 岛上应出现当前歌词行，随时间逐行变化（每行变化都会刷新，不必等整段）。
- 通知栏里会多一条「岛歌词」常驻通知，这是这套方案的载体，属正常现象；
  关掉开关它就消失。
- 日志里会出现 `island | line→<当前歌词行>`，每换一行一条。看到这行说明
  已经发到系统了，剩下的就看机型认不认这张卡。

## 如果还是空

把日志里这三类行发我：

- `island | compat on` / `line→…`：我们这边发出的内容；
- `lyricon | setSong …`：给 HyperLyric/Lyricon 的那条链路；
- `LYRIC 下发系统歌词：N 行`：取词是否成功。

三者都在、岛上仍空，就说明这台机器的岛只接受「焦点通知白名单」这一条路，
需要 Xiaomi 侧放行包名，或者走 HyperLyric + Lyricon Central 的渲染方案。
