# 澜音 v2.6.17

本次包含自 v2.6.14 以来的 QQ 音乐式布局、播放器交互及更新提示改进。

## 界面与播放

- 首页、搜索、歌单、我的及歌单详情统一布局，底部改为“音乐 / 歌单 / 我的”。
- 播放器采用圆形唱片与封面模糊背景；大唱片、底部迷你封面均在播放时旋转，暂停时停转，并尊重系统减少动态设置。
- 点击大封面进入完整歌词，支持键盘操作；封面左右滑动切歌不会误触打开歌词。
- 仅有封面的主播放页居中歌名、歌手及歌词预览，完整歌词页保持原来的左对齐。
- 修正歌曲/歌词标签下划线偏移、长屏留白和手机搜索框绿色焦点框；桌面键盘保留清晰的焦点提示。
- 保留原有音源、播放、歌词、收藏、歌单、多选、下载及设置能力。

## 自动更新

- 开启自动检查时，启动或回到前台发现新版，会自动打开更新页。
- 按设备本地日期，每天最多自动提示一次；同日重开、重复前台事件或更新版本号均不会重复弹页。
- 手动检查不受每日提示次数限制；保留原有检查缓存、忽略版本和自动检查开关。
- 并发检查复用同一请求；检查失败或尚未实际展示不消耗当天次数，后台完成导航后在回到前台时正确补记。
- 不会自动下载或安装 APK，仍需用户在更新页主动操作。

## 稳定性

- 修复快速切换使用同一音频 URL 的歌曲时，旧播放请求可能误停新歌曲的问题；显式暂停与取消仍正常生效。
