# 澜音 v2.6.2

上一版只修好了**全屏歌词**的逐字变色，播放页那张脸下面的两行歌词还是纯文本——所以你看到的还是"没有动画"。这版把播放页也接上了。

## 播放页歌词现在会逐字点亮

- 当前行按 `sungCharCount` 拆成一个个字符的 span，唱到哪亮到哪
- 已唱：青瓷绿 `#a9e4cf` + 12px 柔光
- 未唱：56% 白，比原来更暗一点，进度边界更清楚
- 全屏歌词与播放页共用同一套颜色和时间轴，两个界面表现一致

## 换行有过渡

换到下一句时，旧行先淡出上移（0.16s）、新行淡入上移（0.24s），不再是硬切。外层加了占位高度，换行瞬间下面的内容不会跳。

## 一个实现细节

逐字 span 和 `-webkit-line-clamp` 是冲突的：`display:-webkit-box` 会把每个 span 当成独立盒子，长句会被撑成畸形换行。所以歌词块改成普通块级元素 + `max-height: 44px`（正好两行）截断，长句仍然只显示两行。
