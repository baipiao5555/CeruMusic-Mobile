# 澜音 v2.6.21 · 账号中心、背景与同步修复合并版

本版合并账号中心/自定义背景/WebDAV 工作版本，以及另一个会话已经完成的澜音云歌单同步修复。版本高于两份本地 v2.6.20，使用同一包名与签名，覆盖安装前请备份歌单。

## 本次新增

- **账号与服务中心**：可以选择澜音、QQ音乐、酷狗、酷我、网易云等；按音源实际声明开放账号入口。支持已声明且注册动作的 v2 音源 Native/Web 登录界面、公开账号摘要和退出，来源会话隔离。
- **真实能力边界**：用户提供的聆澜 v2 9.0.0 支持歌单搜索和分享导入，但没有 `accountItems` 或登录 Surface，不能据此登录 QQ/酷狗/酷我。平台选择不代表这些平台已经可登录；音源赞助授权也不是音乐平台账号。
- **自定义图片/视频背景**：本地选择、Blob 持久化、静音循环视频、首帧降级、遮罩/模糊/范围设置；尊重减少动态/省流模式，离开可见范围或后台停止视频。编码仍需设备支持，超限或不安全格式会明确提示。
- **WebDAV 手动备份/恢复**：无需澜音登录；用户明确确认的专用 origin/目录通道、读写测试、独立备份、恢复预览、合并/替换及撤销。条件写入须通过真实 ETag/If-Match 测试，冲突不覆盖。
- 新平台音源会话与 WebDAV 凭据使用 Android Keystore AES-GCM；敏感 Native API 增加仅可信主框架持有的 nonce，防旧 WebView 原生桥旁路。浏览器仅会话内保存，不宣称持久安全仓库。原有澜音 Logto 会话尚未迁移。

## 合并的云歌单修复

- 按歌曲位置或实际 offset 分页；带 total 的短页继续读取，裸数组服务端硬限100时也探测到明确空尾，避免只导入首100。
- 重复/重叠/漏页/不前进/总数与结构异常拒绝提交；读前后版本检查，旧账号请求不得覆盖新账号。
- 云导入一次保存成功后才提交界面；配额失败保留原库，不报假成功。
- 本机编辑与上次云导入基线不同，覆盖前确认；同源公共曲目去重，私有资源按插件/连接隔离。
- 未能确认澜音用户身份时禁止云导入，不能以空 owner 命中其他账号的 cloudId。
- 电脑端相关源码修复已由另一个任务回写；**本 Release 不含重建后的电脑安装包**，真实云/手机/电脑联调仍待验证。

## 保留与未完成

保留 v2.6.19 的旧 WebView 兼容、歌单搜索、本地每日精选、LX 文件导入、圆形唱片与歌词交互。

本地每日精选不是平台个性化日推；本版不是自动双向同步。S3/OneDrive/Google Drive、独立官方平台登录适配器及本人歌单 API、Schema 凭据捕获、多账号连接完整承接、AES 歌单格式、全库 IndexedDB 迁移仍未完成。WebDAV 恢复不携带澜音云关联与凭据，原普通本地编辑也未全部改成原子写入。
