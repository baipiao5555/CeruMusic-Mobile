# 澜音 v2.6.22 · 登录入口修正（本地测试版）

## 已改动

- 删除独立“账号与服务”页及“我的”工具区的重复入口；旧 `/accounts` 链接转到“我的”并打开平台选择。
- 点击“我的”头像行打开紧凑平台选择面板；设置中的“音乐平台登录”使用同一个面板。
- 云歌单的“添加其他服务”真正进入已有 WebDAV 备份恢复页，不再弹旧占位提示。
- Android 增加独立官方网页登录 WebView，不挂载 Capacitor/JavaScript 原生桥；只允许指定平台 HTTPS 域名，证书错误和不受信任跳转拒绝。
- 用户点击“完成登录”后获取白名单会话；复制的凭据经已有 SecretStore/Keystore 加密保存，不提供给音源、不导出到歌单快照。关闭登录页清理该平台主页的临时 Cookie/存储，不清除其他站点或澜音 Logto 会话。
- QQ音乐与网易云接入登录身份核验；匿名、过期、错误或缺少身份的响应不显示“已登录”。新登录失败、存储失败或取消保留原保存会话。
- 酷狗/酷我目前可打开官网并保存网页会话，身份核验接口仍未接入，因此显示“会话已保存 · 身份未核验”，不显示“已登录”。

## 验证与限制

版本号 2.6.22，versionCode 24040，保留原包名与签名。仅本地构建，不自动上传 GitHub。

Chrome 中实际 Vue 页面入口与移动宽度检查、真实 TypeScript 账号生命周期（合成原生响应）、Web 构建与 Android release 编译已验证。合成测试不代表真实平台登录通过。

本次未连接 Android 真机或真实用户账号；QQ/网易云真实登录、Cookie 清理、Keystore 重启恢复、网页扫码/验证码、第三方登录重定向仍须真机验证。浏览器可能有不同 Cookie path/subdomain，本版不宣称浏览器全部临时数据已彻底清除。

Web 预览不能读取其他网站会话，不提供假成功按钮。本版未新增本人歌单列表/API、平台会员播放或平台日推；没有扩大 WebDAV 到自动双向同步。不是整份六页设计的完整实现。
