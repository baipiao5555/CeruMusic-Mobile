## WebDAV 双向同步

- 每个连接保存上次成功同步基线、远端强 ETag、时间与冲突数；本地库与远端都用可移植白名单快照。
- “立即双向同步”执行三方比较：只有本地变化时条件写入远端，只有远端变化时应用到本地，两边都变化时合并。
- 同一歌单两边都改时保留本地原 ID，并为远端版本创建「名称 (冲突副本 日期 时间)」；不覆盖任何一方。
- 首版不传播删除：单边删除会恢复并提示，避免误删远端或本机歌单。
- 写入必须通过真实 ETag 条件验证；412 会重读并重试一次，连续 412 安全失败；远端损坏、401/403、重定向、超时、离线都不会修改本地库。
- 页面打开时可启用每 3 分钟自动同步，同一设备只允许一个自动同步目标；隐藏、离线或正在操作时跳过。
- 保留原有独立备份、恢复预览、合并/替换恢复和撤销；手动备份文件与双向同步当前文件分开。

## 网易云歌单导入

- 已登录网易云后，在“登录音乐平台”中点击“读取平台歌单”，可读取账号歌单目录、预览曲目数量并导入为新的本机歌单。
- 读取链路：`account/get` 确认当前网易云身份 → `user/playlist` 读取歌单目录 → `v6/playlist/detail` 读取有序曲目 → `song/detail` 补全详情页未返回完整元数据的曲目。
- 会话从 Android Keystore 安全仓库读取，仅通过 `httpRequest`（CapacitorHttp）发送 `Cookie` / `Referer` 请求头；不把平台凭据交给音源插件，也不写入普通 `localStorage`。
- 导入曲目使用 `providerId: 'wy'`、稳定的平台歌曲 ID，保留歌单顺序与标题/歌手/专辑/时长/封面；导入目标是本机歌单，不会出现在“云端歌单”页。
- 导入只保存曲目信息；播放仍取决于已安装并启用的网易云音源插件，平台登录或导入本身不授予会员播放权限。
- QQ、酷狗、酷我、咪咕、汽水的平台歌单读取仍**未完成真实账号验证**，界面会明确显示不支持原因，不会展示虚假的歌单或导入成功。
- 当前没有真实网易云账号和 Android 真机可用：公开歌单/歌曲接口已用真实网络请求验证；登录后的目录读取用合成会话和固定响应验证请求头与解析逻辑。真机登录态、验证码、风控和会员播放权限仍需实机确认。
