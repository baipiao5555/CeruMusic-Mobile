# 澜音 v2.6.28 · 旧 WebView 兼容补丁

本版在 v2.6.27 基础上补充旧 Android WebView 的降级路径，保留 v2.6.27 的平台登录移除、澜音云端歌单、WebDAV 双向同步、平板布局和本会话最新动效。

## 兼容性

- 发现页音源弹层增加 `80vh` 回退，在不支持 `dvh` 的旧 WebView 上仍能限制高度。
- 搜索框在不支持 `:has()` 的旧 WebView 上增加 `:focus-within` 焦点提示；支持 `:has()` 时仍只在键盘焦点下显示。
- 播放器封面连续展开、搜索/弹层动效和列表窗口化全部保留；系统开启“减少动态效果”时回退。

## 未改变

- 不重新引入内置 QQ 音乐、网易云、酷狗、酷我、咪咕、汽水平台登录。
- 不改变澜音账号登录、云端歌单、WebDAV 同步和应用级自动同步。

## 验证

- `npm run build` 通过。
- 平板布局回归：手机 390×844、平板 768×1024、1024×768、1280×800，287/287 通过。
- 搜索入口动效、弹层焦点/退出、长列表窗口、播放器封面展开/收起和搜索联想回归通过。
- 未做 Android 6–11 旧 WebView 真机矩阵；旧系统兼容性仍需实机确认。
