# 澜音 v2.6.3

上一版把播放页和全屏歌词的逐字变色修好了，但**共享出去的那条歌词**（系统歌词 / 锁屏 / Lyricon 系灵动岛）还是只会整行换行。这个版本把它接上了。

## 共享歌词也能逐字动

共享歌词走的是系统的 `MediaSession` 歌词通道：

- **Lyricon / SuperLyric 系**（HyperOS、ColorOS 等 ROM 里那些支持逐字歌词的歌词组件）：读 `RichLyricLine.words` 做逐字填充，**现在会跟着唱**；
- **ColorOS 原生锁屏歌词**：这条通道只接受行级 LRC（`lyricType: 0`），系统侧只能做整行高亮，这是格式本身的上限。

## 没有字级时间怎么办

大多数音源只提供行级时间。之前这种歌词共享出去就只有行，现在按字数估算出每个字的时间：

- 中日韩字符 235ms/字，拉丁字母与符号 95ms/字，空白不计；
- 演唱总长不超过这一行到下一行的间隔（最多 15 秒），也不会长于按字数估出来的时长；
- 唱完立刻整行点亮，间奏不再被算进演唱时间。

有真实字级时间的音源仍然优先用真实时间，不会被估算覆盖。

## 一首歌的完整一致性

播放页预览行、全屏歌词、共享歌词，这三处现在用的是同一套时间：

- 播放页预览：逐字 span + 青瓷绿（`#a9e4cf`）；
- 全屏歌词：逐字 span + 青瓷绿 + 淡光晕，行切换时 0.24s 上滑；
- 共享歌词：同样的字级时间交给系统。

## 细节

- 逐字数据有 5000 字的预算上限：超出后自动退回行级，避免 Android Binder 的 1MB 上限导致的 `TransactionTooLarge`；
- 500 行歌词、每行十几字的实测 payload 约 59KB，远低于上限。
