# 澜音 v2.6.5

## 搜索：歌名更准，还能按歌词找歌

### 歌名搜索
- 输入完整歌名时只给同名/同名开头的结果，不再把「歌名里带这个字」的几十首一起列出来。
- 只输入一个字/一个词时仍保留模糊搜索，但按「开头命中 > 中间命中」「歌手命中 > 专辑命中」排序，越像的越靠前。

### 歌词搜索（新）
- 搜索框右侧新增「歌名 / 歌词」切换，选择会被记住。
- 切到歌词后输入一句歌词（比如「气氛不算融洽」），先查歌词库，再回当前音源找可播放的那首。
- 命中结果下方会显示对应的那句歌词，方便确认。
- 歌词库里有、但当前音源搜不到的歌会单独列出来，提示换音源——不会让结果页面空着不说原因。

### 顺带
- 搜索结果的空态文案按「歌名 / 歌词」分开，歌词模式会提示「换一段更短、更独特的歌词」。
