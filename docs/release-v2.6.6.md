# 澜音 v2.6.6

## 洛雪音源兼容

- 支持从公网 HTTP(S) 链接或本地文件安装洛雪 LX 音源，并保留澜音 v2 插件支持。
- 根据脚本声明接入歌曲目录、播放地址、歌词与封面；同平台多个音源可单独选择，已有歌曲优先使用原插件。
- 修复二进制响应、脚本请求上下文和音质匹配；歌曲与音源没有共同音质时明确提示切换音源。
- 支持链接更新、失败回滚和重启后恢复。

## 搜索与播放

- 输入一个字或关键词即可联想包含关键词的歌名，去重后最多 10 条。
- 修复快速改词、中文输入法、清空、切换音源及跨页面返回时的旧结果覆盖问题。
- 修复发现页切换音源和歌单分类时的请求竞态。
- 播放封面改为圆形，播放时旋转，暂停或缓冲时停在当前角度，恢复播放后继续旋转。
- 保留原有界面布局，支持系统减少动态效果设置。

## 安全与验证

- 洛雪脚本在受限 Worker 中运行，阻止直接联网和页面导航绕过；网络访问由宿主校验。
- 补齐本地域名尾点、IPv4-mapped IPv6 等地址形式的拦截，并验证停用后的 Worker 和未完成请求清理。
- 通过搜索、播放器、洛雪兼容、音质和网络策略回归，以及小屏、手机和桌面尺寸的生产页面验收。
- 未进行 Android 真机安装测试；第三方音源服务的可用性由其提供方决定。
