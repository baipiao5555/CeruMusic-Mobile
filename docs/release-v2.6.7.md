# v2.6.7

三件事：锁屏歌词换歌后不再串位置、全屏歌词页进入沉浸模式、歌词字体可以换。

## 修：换歌后锁屏 / 岛上的歌词位置错乱

上一版把「播放进度」交给系统服务托管，服务里有一条守卫：进度不允许倒退（防止 WebView 在后台被限流时把歌词拉回开头）。
问题是换歌也被这条守卫拦住了——新歌刚开始是 0，比上一首末尾小得多，于是被当成「过期进度」丢掉，岛和锁屏继续停在上一首的位置。

- 原生 `MediaPlaybackService` 现在记录当前曲目标识（`songKey`），换歌后的第一帧进度直接采纳并重置时间轴，不再走「禁止倒退」判断。
- WebView 侧的进度、seek 请求都带上同一个标识，原生据此识别换歌。
- 换歌瞬间不再出现「clamp stale progress 341 -> 522」这类自增，歌词从第一句正常开始。

## 新：全屏歌词页沉浸

进入歌词页 1.6 秒后，顶部按钮、底部进度与播放控件、系统状态栏一起退场，只留歌词。

- 轻触屏幕、上下滑动歌词，控件立刻回来；停手 3.2 秒后再次退场。
- 控件收起时点歌词只负责唤出控件，不会误触跳转；控件在时点歌词仍然是跳转到那一句。
- Android 返回键优先收起歌词层，再按一次才退出播放页。

## 新：歌词字体

设置 → 歌词 → 歌词字体：

- 系统默认：跟随手机 UI 字体，最稳妥
- 宋体 · 衬线：唱片内页的观感
- 楷体：偏手写，适合慢歌
- 圆黑：圆润的现代黑体

只作用于歌词文字（全屏歌词、播放页歌词预览），界面其余部分保持系统字体。每个选项都带字体兜底，设备缺字时会自动退化，不会出现方框。
