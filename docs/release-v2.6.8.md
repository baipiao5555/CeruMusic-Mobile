# v2.6.8

两件事：字体设置现在真的会换掉整个 App 的字，而且换了之后一定看得出变化。

## 修：切了字体没反应

上一版只把字体用在了歌词上，界面本身还是系统字体；而且三个选项里有的是手机根本不带的字体名（楷体、圆黑），系统找不到就悄悄退回到原来的黑体——看起来就像「设置无效」。

这一版改了两件事：

- **作用范围**：改成界面 + 歌词一起换。选一次，标题、正文、按钮、设置项、播放页、全屏歌词全部跟着变。
- **兜底换掉**：不再依赖手机自带字体。App 里内置了一份**文楷**（霞鹜文楷，SIL OFL 授权），只保留 GB2312 一级常用字和拉丁标点，子集 887KB，任何机型选它都一定变样。
- 其余选项全部落到 CSS 通用族（`serif` / `monospace` / `sans-serif`），不再出现「字体不存在 → 无变化」。

## 字体选项

设置 → 外观 → 字体：

| 选项 | 观感 |
| --- | --- |
| 系统默认 | 跟随手机 UI 字体，最稳妥 |
| 文楷 · 内置 | 随包的楷体，笔画带手写味，慢歌和长文最明显 |
| 宋体 · 全衬线 | 标题正文都变衬线，像唱片内页 |
| 等宽 | 字距均匀，像歌词本敲出来的 |

旧版本存过的「楷体 / 圆黑」会平滑迁移到「文楷 · 内置」，不用重新选。
