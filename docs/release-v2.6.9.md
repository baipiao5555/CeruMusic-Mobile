# 澜音 v2.6.9

## 返回键按层级走

- **发现**：连按两次才退出应用（中间会有一次「再按一次退出应用」的提示）。
- **我的**：返回一次到歌单，再返回一次到发现。
- **歌单**：返回一次到发现。
- **搜索**：返回一次到发现。
- 其余页面（歌单详情、设置、播放页等）保持原来的行为，返回上一页。

## 字体多两种

现在一共 5 种：系统默认、文楷（内置）、得意黑（内置）、宋体衬线（内置）、等宽。
切换后**整个界面和歌词一起换**，缺字时自动回落到系统字体。
得意黑适合标题，宋体衬线像唱片内页，等宽适合看歌词。

## 播放缓存

- 默认开启，边播边把音频写到手机本地（最多 512MB，超出按最久未用淘汰）。
- 同一首歌再播直接读本地，不再走流量，也不怕网络抖动。
- 设置 → 播放 → 可以看当前占用、随时清理。
- 只监听本机回环地址，并带一次性 token，局域网里的其它设备访问不到。
- 网页环境没有这个能力，会自动退回原来的直连方式，不影响调试。
