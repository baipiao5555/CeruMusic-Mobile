# 澜音 v2.7.0 · 本地文件音源自动更新修复

本版修正「从文件安装的音源不会自动更新」的问题，并补齐本地音源的更新地址管理。

## 修复

- 自动更新不再只检查 `sourceUrl`。本地文件安装的插件现在使用独立的 `updateUrl`，同样参与启动检查和「检查全部更新」。
- 从文件安装后，如果插件 manifest 的 `homepage` 直接指向 `.js`，或洛雪音源头部声明了 `@updateUrl`，会自动识别为更新地址。
- 插件详情新增更新地址管理：没有地址时可以填入同一音源的 `.js` 链接；已有地址可以修改，地址失效后不必卸载重装。
- 绑定或修改更新地址时会先下载并校验 manifest id，地址返回其它音源时拒绝保存，避免更新成错误插件。
- 升级后首次启动会为旧安装记录补全更新地址，已有链接订阅继续正常自动更新。
- 插件列表明确区分「链接订阅 · 自动更新」「文件安装 · 自动更新」和「文件安装」，帮助文案同步更新。
