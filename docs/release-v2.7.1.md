# 澜音 v2.7.1 · 搜索与页面切换掉帧修复

本版处理自定义背景下搜索、Tab 与音乐馆切换卡顿的问题。不是新增动画库，而是减少转场期间的整页挂载、滚动和多层合成。

## 修复

- 移除路由每次切换都会触发的 `window.scrollTo(0, 0)`。页面使用自己的滚动容器，这个窗口滚动没有必要，而且会带来额外排版。
- 搜索、推荐、歌单、我的与音乐馆改为空闲时逐个预热，之后保留页面，切换只改可见性，不再反复销毁和重新挂载。
- 页面切换不再让新旧两张整页同时做 opacity 交叉渐变；新页面只做一次短距离 `translate3d` 入场，Tab 约 0.16s，其余页面约 0.19s。
- 搜索页仍在入场结束后才聚焦输入框；立即返回会取消待执行的键盘聚焦，系统“减少动态效果”开启时直接跳过转场。
- 音乐馆保留已加载内容，重新进入时继续刷新；离开时在途请求立即失效。
- 推荐页不再在进场期间反复读取和设置滚动位置。
- 自定义背景、播放器封面连续展开、歌词与本地音源自动更新逻辑保留。
