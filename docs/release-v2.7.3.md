# 澜音 v2.7.3 · 弹层重复入场与收藏/最近播放修复

基于 v2.7.2，包含本轮弹层修复，以及另一会话完成的收藏/最近播放修订。

## 弹层修复

- 音质、新建歌单、删除下载等入口：一次点击只执行一次，但 Vue 入场结束后旧 CSS keyframe 又重新启动，使弹层回跳约 28px，看起来像打开两遍。
- 移除共用基类入场动画。Vue 管理的弹层只保留一套过渡；没有 Vue Transition 的四种弹层显式使用 sheet-standalone，仍保持一次入场。
- 对齐遮罩和面板过渡时长，避免关闭提前截断；减少动态效果下不再额外上弹。
- 不叠加业务防抖，保持正常第二次点击、确认/取消和数据写入语义。

## 收藏与最近播放

- 喜欢、最近进入各自独立详情列表，兼容旧 query 入口。
- 歌曲计数对应完整入库合集；收藏/历史计数随操作更新。
- 清空最近播放先确认，只清历史，保留收藏、歌单和播放队列；存储失败不冒充成功。
- 保留当前 UI、字体、背景、单层页面动效及 v2.7.2 播放/音质/网络安全修复。
