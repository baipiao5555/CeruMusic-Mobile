# 澜音 v2.7.4 本地合并测试包：弹层入场不再重播

基于已发布 v2.7.2，并保留另一会话完成的 v2.7.3 收藏/最近播放修订。

## 本次修复

- 音质、新建歌单、删除下载等按钮实际上只触发一次。弹层先完成 Vue 过渡，随后恢复基类 `fade-in`/`sheet-up` CSS 动画，造成约 28px 回跳和第二次入场。
- 移除共用基类动画。由 Vue Transition 管理的弹层只保留一套过渡；没有 Vue Transition 的四种弹层显式使用 `sheet-standalone`，继续保持一次入场。
- 遮罩和弹层过渡时长对齐，离场不再提前截断；减少动态效果下独立弹层也不再重新上弹。
- 不再对业务按钮叠加防抖，不改变正常第二次点击、数据写入或确认/取消语义。

## 验证范围

- `test-sheet-buttons.mjs`：真实 Vue 页面中点击音质、加号、删除、设置、导入，记录事件、DOM 插入和每帧位移；创建/删除/音质选择分别检查只写入一次。
- `test-sheet-animation-replay.mjs`：原版能确认重播；修复版覆盖开关、键盘/焦点、独立弹层、减少动态效果和关闭途中重开。
- 同时回归收藏/最近播放和 v2.7.2 行为。完整实际结果见本次交付 evidence。
