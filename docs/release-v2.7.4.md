# v2.7.4 正式版

基于用户已测试的第七轮音源市场版本，补齐 Android 13 以下系统与平板适配。保留用户选定的 A 样式。

## 本地音乐与下载

- “扫描文件夹 / 下载位置”采用并排圆角按钮，直接调用系统目录选择。
- 默认局部扫描，包含应用下载与所选文件夹及子目录；全局媒体库扫描需要手动选择并授权。
- 音乐优先模式过滤疑似录音、提示音和短音频；可关闭规则或恢复全部，只改变显示，不删除文件。
- Android 10+ 默认共享 Music/CeruMusic；可改为用户授权目录。旧下载提供复制导出，原文件保留。

## 音源市场

- 保留 URL/文件导入、获取过程反馈、更新/回滚与逐项权限确认。
- LX 五平台公开推荐歌单、目录与歌单导入；安装后按实际初始化平台显示，不虚构能力。
- 独立/聚合音源按平台整理，同一录音多来源聚合；播放音质降级和选定来源失败回退。
- 封面延迟补全；旧插件操作上下文、HTTP 编码与 HMAC 兼容处理仍受已有授权约束。

## Android 6–12（API 23–32）

- 移除 API 23 无法调用的目录判断与下载长度方法，改用 API 21 目录校验和兼容长度头解析。
- 高版本导航栏/状态栏/刘海屏属性拆到 values-v27/v28/v29，保留低版本完整主题继承。
- API 23–25 使用可读的深色导航栏背景，避免浅色背景配白色系统图标。
- 共享经典兼容引导增加 CSPRNG randomUUID 后备，供主 WebView、插件 iframe 与 Worker；没有不安全随机数回退或额外授权。
- 明确面向 Chromium/WebView 87+ 的构建目标；动态视口单位提供 vh 回退。旧系统仍需可支持该应用的 WebView，请更新到系统可用版本。

## 平板

- 本地音乐宽屏两栏：左侧扫描/目录控制，右侧曲目列表；窄屏继续保持手机布局。
- 音源市场三列卡片，设置/详情/来源弹层居中并限制高度；下载内容限制宽度。
- 保留导航、播放器、主题与窗口尺寸变化行为，支持横竖屏和较窄的多窗口布局。

## 验证与边界

- API 23/28/29/32 文件后端合同回归、版本化主题测试、共享兼容引导测试通过。
- NewApi 专项 lint 报告 0 项问题。分析工具仍对第三方 Kotlin 2.3 元数据产生兼容诊断，未据此声称第三方全部代码都得到完整分析。
- 旧 WebView 功能缺失模拟（Array.at、randomUUID、dvh）以及 390/600/768/1024/1280 宽度布局回归通过。
- 平板原有 287 项检查、14 个核心/市场测试、5 个浏览器套件通过。歌单文件解析测试已改为针对当前源码，不再读取旧工作副本。
- 这是本地合同/浏览器验证，**没有 Android 真机实测**；本机模拟器加速驱动缺失。具体厂商系统、旧 WebView 和第三方音源服务仍需实际设备反馈。
- APK 签名、包名、版本和资产一致性在发布前核验。SHA256 见发布附带校验文件。

本版按用户最新要求发布为正式版，非测试版、非 prerelease。未增加全文件管理权限；公开源码不包含签名密钥或用户截图。
