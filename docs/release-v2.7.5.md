# v2.7.5 正式版

基于公开发布的 v2.7.4，保留音源市场、Android 6–12 与平板适配，并完成用户已测试的歌单导航修订。本版按正式版发布，非测试版、非 prerelease。

## 歌单

- 歌单内可直接搜索歌名、歌手或专辑；搜索结果不影响原歌单顺序和内容。
- 支持按保存顺序、歌名和歌手切换排序；保留随机播放、多选、下载和加入队列。
- 播放中的歌曲可在歌单内精确定位并高亮，同名歌曲不会误定位到其他音源。
- 列表滚动后提供回到顶部；收藏与最近列表复用相同的搜索和导航行为。
- 歌单歌曲恢复真实封面，按歌曲所属音源懒加载，失败时保留默认图。

## 音源更新

- 已启用且带更新地址的音源会在应用启动时自动检查并安装安全更新，不再只是提醒。
- 插件 ID、发布身份、版本和内容哈希都会校验；旧配置与回滚能力保留。
- 权限扩大、平台减少、降级或同版本内容变化不会被静默覆盖，仍进入人工确认。
- 本地文件导入的音源没有更新地址时，仍可在来源详情绑定同一插件地址。

## 播放器与稳定性

- 从迷你播放器直接打开播放队列时，不再同时运行封面展开动画，避免大封面盖住队列。
- 队列、音质和设置弹层出现时，会清理仍在运行的封面克隆层；普通封面展开/收起动画保留。
- Android WebView 渲染进程失效后会移除旧界面并重建 Activity，降低锁屏后永久白屏的概率。
- 保留 Android 6–12 的系统兼容处理与平板/横竖屏布局。

## 验证与边界

- 歌单封面真实请求并解码成功；201 首歌单内的搜索、排序、多选、定位与回顶回归通过。
- 本地文件绑定更新地址 13 项、链接安装与启动自动更新 7 项通过；更新节流和关闭开关行为保留。
- 播放器封面展开、收起、队列直接打开及减少动态效果模式通过。
- 14 个核心/市场测试、5 个浏览器套件与 287 项平板布局检查通过；生产构建显示版本 v2.7.5。
- APK 为正式 Release 签名，包内 60 个网页资源与最终 `dist` 逐字节一致。
- 本环境没有连接 Android 真机。锁屏数分钟后的实际恢复、厂商 WebView 与线上音源行为仍需设备使用反馈。
