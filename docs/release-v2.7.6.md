# v2.7.6 正式版

修复 v2.7.5 的应用更新提示版本比较问题。功能本身没有移除，问题只出现在版本号判断。

## 更新提示

- 正式版现在会被识别为高于同数字测试版：`2.7.5` > `2.7.5-playlist.2`。
- 继续支持旧版 `2.3.1-mobile.16` → `2.3.1-mobile.17` 这类预发布递增比较。
- 相同正式版本仍不会重复提示；用户已忽略的版本也不会再次弹出。
- 应用启动和回到前台时仍会检查更新，成功后自动进入更新页；同一天最多自动提示一次。

## 兼容范围

- 应用内更新和音源插件自动更新共用同一套严格版本比较，行为保持一致。
- 保留 v2.7.5 的歌单封面、歌单搜索/定位/回顶、队列动画修复和 WebView 渲染恢复保护。
- Android 6–12 与平板适配不变。

## 验证

- 版本比较单元测试覆盖测试版到正式版、同版本静默、忽略版本和旧 mobile 预发布递增。
- 真实浏览器启动链路测试通过：远端出现更新时自动打开更新页，说明、下载按钮、忽略版本和当天限频正常。
- 音源插件自动更新 7/7 与本地更新地址 13/13 回归通过。
- 生产设置页显示 v2.7.6；APK 签名、包名和网页资产在发布前核验。
- 未连接实体 Android 设备；厂商 WebView 与真实系统安装器行为仍以设备反馈为准。
