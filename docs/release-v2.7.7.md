# v2.7.7 正式版

基于 GitHub v2.7.6，合入 MusicFree 音源兼容、音源市场 A 方案和播放链路修复。

## MusicFree 音源兼容

- 支持在线插件直链、GitHub 页面链接转 raw，以及 MusicFree 订阅 JSON。
- 订阅 JSON 含 `plugins` 列表时逐个获取插件，每一项仍单独确认权限。
- 混淆插件按文件名安全推断平台/版本，不执行代码；未知分类默认从 128k 起播。
- 保留搜索、榜单、推荐分类、推荐歌单、歌单详情和歌单导入。
- 不接入 MusicFree 的账号、播放器、本地文件等非音源能力。
- 修复推荐分类嵌套返回被解析为空的问题；“听点喜欢的”可显示 MusicFree 歌单。

## 音源市场 A 方案

- 手机端发现页改为单列清单：图标、名称/版本、说明、格式标签、获取按钮。
- 平板保留三列卡片布局。
- 格式标签并入说明行，右侧只保留获取/已安装按钮，降低行高。
- 搜索框去除绿色焦点轮廓。
- 保留 B 管理界面：平台来源、插件管理、更新、回滚、配置和卸载。

## 播放修复

- 移除后续版本添加的音频焦点抢占与焦点失败自动暂停，恢复官方 v2.7.6 的原生播放服务。
- 不再因为内部 403/404 探测丢弃最终有效的播放地址。
- 播放器、取址和缓存使用官方 v2.7.6 基线。

## 验证

- MusicFree 订阅 `padao/main.json` 实测识别为 6 个插件并进入逐项权限确认。
- QQ MusicFree 推荐分类 64 个、歌单 30 个；酷我 82/22；酷狗 82/30；网易云 70/30；咪咕 62/30。
- MusicFree 首页“听点喜欢的”实测出现 16 张歌单卡。
- MusicFree 内部 404 探测后仍可返回有效地址并播放真实 WAV。
- A 方案在 412px 宽度下实测行高 74px、按钮/标签对齐、搜索框无焦点轮廓；歌词页标题中心偏差 0。
- Web 构建、Capacitor sync、Android Release 构建和 APK 网页资产一致性在打包时核验。
- 未连接实体 Android 设备；真机播放、厂商系统和第三方平台可用性仍需用户复测。
