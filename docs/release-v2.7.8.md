# v2.7.8 正式版

在 v2.7.7 基础上增加“与其他应用同时播放”，并保持 MusicFree 源兼容和 A 市场布局。

## 与其他应用同时播放

- 设置 → 播放新增开关，默认开启。
- 开启时不申请独占音频焦点，澜音可与其他应用一起播放。
- 关闭时申请独占焦点；焦点申请被拒或刚开始播放时收到短暂焦点丢失，不会自动暂停。
- 只有播放稳定超过约 2.5 秒后真正失去焦点才暂停。
- 旧设置自动迁移到“同时播放开启”，避免升级后仍走旧的独占逻辑。
- 暂停、停止或服务销毁会释放焦点。

## 保留

- MusicFree 插件直链、GitHub 页面链接和订阅 JSON 导入。
- MusicFree 搜索、榜单、推荐歌单、歌单详情和歌单导入。
- A 方案单列音源市场；格式标签并入说明行，右侧只保留获取/已安装。
- v2.7.7 的 WebView 白屏恢复和本地扫描快照逻辑不变。

- Web 构建、Capacitor sync、Android Release 构建通过。
- APK 版本 `2.7.8 / 24081`，同签名；包内 62 个 Web 文件与最终 dist 逐字节一致。
