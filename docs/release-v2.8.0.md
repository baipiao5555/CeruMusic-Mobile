# v2.8.0 正式版

重点修复“同时播放”在部分应用下仍会被暂停，并保留 2.7.10 的更新安装修复。

## 同时播放

- 默认开启“与其他应用同时播放”开关。
- 原生服务在混音开启时不申请独占焦点，关闭时才申请。
- HTML 音频在混音模式检测到非用户暂停（系统/其他应用抢占）时自动尝试恢复，最多 2 次。
- 用户主动暂停、切换歌曲、播放结束不会触发自动恢复。
- WebView 渲染进程保持 IMPORTANT 优先级。
- 部分应用会强制独占音频焦点或限制后台 WebView，仍可能无法完全混音；这需要具体应用和真机日志继续确认。

## 保留

- 2.7.10：更新 APK 写入应用私有 Downloads，使用 FileProvider 安装，不再写入音乐 MediaStore。
- 2.7.9：ColorOS 应用内 OAuth 登录回跳。
- MusicFree 导入、榜单/歌单、A 音源市场、B 管理界面、本地扫描快照。

## 验证

- 自动恢复回归：模拟系统暂停后音频恢复；用户主动暂停保持暂停。
- 音频焦点契约测试通过。
- Web 构建、Capacitor sync、Android Release 构建通过。
- APK 版本 `2.8.0 / 24084`，同签名；包内 Web 文件与 dist 一致。
- 未连接实体 Android 设备；OriginOS/ColorOS 真机同时播放仍需用户复测。
